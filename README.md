# 📊 전국 시·군·구 소득 대비 부동산 가격(PIR) 비교 대시보드

행정구역(전국, 17개 시·도 및 서울 주요 권역) 단위의 평균 주택 매매가격과 평균 연소득 데이터를 결합하여, 지역별 **'소득 대비 주택가격 배수(PIR = 주택가격 ÷ 연소득)'**를 계산하고 비교·시각화하는 반응형 웹 대시보드입니다.

---

## 🚀 빠른 시작 (가장 쉬운 실행 방법)

### 방법 A. 원클릭 실행 (초보자 추천 ⭐)
* 탐색기에서 **`run.bat`** 파일을 더블 클릭하면 자동으로 서버가 켜지고 웹 브라우저(`http://127.0.0.1:8000`)가 즉시 열립니다.

### 방법 B. 파워쉘에서 실행
```powershell
cd C:\AI-study\test1\korea-pir-dashboard
.\.venv\Scripts\python.exe main.py
```
실행 후 인터넷 브라우저에서 **`http://127.0.0.1:8000`**에 접속하시면 됩니다.

## 📊 핵심 기능

1. **4대 핵심 요약 카드**: 전국 평균 PIR, 최고/최저 지역, 전체 분석 지역 수 한눈에 파악
2. **쉽게 이해하는 PIR 가이드**: 5배 이하(안정), 5~10배(적정), 10~15배(주의), 15배 초과(고부담) 해석 기준 제공
3. **인터랙티브 랭킹 차트**: Chart.js 기반 막대 그래프, PIR 높은순/낮은순 실시간 정렬
4. **내 소득 맞춤 계산기**: 내 실제 연봉을 입력하면 지역별 구매 소요 햇수와 진입 용이도 자동 계산
5. **관심 지역 1:1 맞비교**: 원하는 지역들을 체크박스로 골라 나란히 집값/소득 비교
6. **전국 정밀 데이터 테이블**: 23개 전체 행정구역 실시간 키워드 검색 및 순위표
